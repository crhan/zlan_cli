TCP调试助手

发布时间：2009-10-29 作者：上海卓岚

TCP/IP调试助手是用于在TCP/UDP的应用层上进行通信连接、数据传输的Windows工具。所谓应用层上就是说，TCP调试工具是不涉及TCP/IP协议层实现的问题，而只是利用TCP/IP进行数据传输。从另外一个角度讲，它是将BSD socket的接口的每个函数都让用户可以通过界面进行独立的调用。比如用于TCP连接的connect，变为“连接”按钮；比如发送数据的send函数变为“发送”按钮。以下列出了互联网上流行的几种TCP调试工具。

卓岚TCP UDP调试助手

下载：SocketDlgTest(V3.49)

名称：卓岚TCP/UDP调试工具

特点：支持文件发送、接收；界面简洁；稳定可靠；可16进制显示；定时发送；目的IP支持域名；UDP组播支持；绿色软件无需安装。

用户手册：SocketTestDlg用户手册。

推荐指数：10

TCP-UDP服务管理V1.03

下载：TCP-UDP服务管理 V1.03

名称：TCP-UDP服务管理 V1.03

特点：定时发送、十六进制显示。

推荐指数：5

网络调试助手

下载：TCP-UDP服务管理 V1.03

名称：TCP-UDP服务管理 V1.03

特点：定时发送、十六进制显示。

推荐指数：5
